# 🛒 Amazon Clone Website

A responsive front-end Amazon clone built using HTML, CSS, and JavaScript. This project recreates the basic UI and shopping experience of the Amazon homepage with a clean design, responsive layout, interactive search functionality, and modern styling.

---

## 📌 Features

* Responsive Amazon-inspired homepage
* Navigation bar with search section
* Product category boxes with images
* Interactive search functionality using JavaScript
* Cart and Sign-in button interactions
* Hover effects and modern UI styling
* Fully beginner-friendly project structure
* Mobile responsive layout

## 📖 Functionality Overview

### 🔍 Search Feature

* Users can enter product names in the search bar.
* JavaScript handles search button click events.
* Displays alert messages for demo search functionality.

### 👤 Sign In Button

* Clicking the sign-in section triggers a demo alert.

### 🛒 Cart Feature

* Cart icon interaction displays cart-related alert messages.
